# Lecture 08 · Positioning + Layout Thinking

**Web Designing** · Module: CSS · Technoledge Eduresearch Pvt. Ltd. · Trainer: Gourav Kashiv

## Six things to remember

1. Normal flow: blocks stack, inline flows.
2. relative stays in flow, creates a containing block.
3. absolute leaves the flow, placed on its containing block.
4. fixed = the screen. sticky = scrolls, then sticks.
5. z-index only competes within one stacking context.
6. Find the containing block before you fix anything.

2. **Open** the folder in VS Code.
3. **Run** any `.html` file: right-click → **Open with Live Server**.
